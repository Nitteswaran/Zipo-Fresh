# Zipo Fresh — Website

**Live Grocery Store Website** for Zipo Fresh, Taman Musim Bunga, Ipoh, Perak.
Built in pure HTML/CSS/JS — zero frameworks, zero build steps, maximum SEO.

## Structure
- `index.html` — Homepage
- `shop.html` — Product gallery
- `blog.html` — Blog listing
- `blog-post.html` — Individual blog post
- `about.html` — About page
- `contact.html` — Contact & location
- `data/posts.js` — Blog posts (edit to add posts)
- `admin/index.html` — Blog admin panel

## Adding Blog Posts
1. Open `/admin/` in your browser
2. Click **New Post**, fill in the form
3. Go to **Export Data**, click **Copy to Clipboard**
4. Paste into `data/posts.js` and save

## Customisation
- Replace `601XXXXXXXXX` with your real WhatsApp number
- Replace `zipofresh.com.my` with your real domain
- Replace images in the `images/` folder
